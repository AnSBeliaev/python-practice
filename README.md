# Практика по Python: блоки 1-4

21 задача из реальных ситуаций на проектах: баги из прода, импорт больших файлов, повторы запросов к нестабильному API, лимиты внешних сервисов, гонки при списании баланса. В каждом файле задачи есть описание ситуации, что сделать и какой вопрос по этой теме задают на собесе.

К каждой задаче есть тесты. Задача решена, когда её тесты зелёные.

## Запуск

Нужен Python 3.11 или новее.

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

pytest                      все тесты
pytest block1               один блок
pytest -k test_03           одна задача
pytest -x                   остановиться на первой ошибке
```

Сейчас все тесты красные, так и должно быть.

## Правила

- Решать по порядку, блок за блоком.
- Документацию Python читать можно и нужно. Готовые решения не искать, AI не просить написать код: на собесе подсказок не будет.
- Тесты не менять. Сигнатуры функций тоже, если в задаче не сказано иное.
- После каждой задачи ответить вслух на вопрос "На собесе" из её описания. Если ответ не получается - задача не закрыта, даже если тесты зелёные.
- В задаче 4.2 тестом проверяется только результат. Замер времени и объяснение цифр - обязательная часть.
